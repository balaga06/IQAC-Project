# JNTUK IQAC Academic Monitoring Portal

## Overview

A full-stack web application developed to digitize IQAC academic monitoring and results management for JNTUK. The project includes a dynamic Admin Panel for content management and a public website that automatically displays uploaded content.

## Features

* Admin Authentication (JWT)
* Dynamic CMS
* Page Management
* Notifications
* Document Upload
* Image Upload
* Responsive UI
* PostgreSQL Database

## Tech Stack

* React.js
* Node.js
* Express.js
* PostgreSQL
* Tailwind CSS
* JWT Authentication
